#  Whatslab Clone (MVP)

Este é um projeto simples em **React + TailwindCSS** que simula um chat estilo WhatsApp.  
Ele permite adicionar usuários, selecionar um deles e enviar mensagens com avatar colorido, nome e horário.

##  Funcionalidades

-  Adicionar usuários dinamicamente via modal  
-  Selecionar usuário antes de enviar mensagem  
-  Enviar mensagens com hora e avatar (primeira letra do nome + cor aleatória)  
-  Validação com mensagens de erro quando:
  - Não houver usuário selecionado  
  - A mensagem estiver vazia  
-  Histórico de mensagens com barra de rolagem  
-  Estilização usando **TailwindCSS**

##  Tecnologias utilizadas

- [React](https://react.dev/)  
- [TailwindCSS](https://tailwindcss.com/)  
- JavaScript (ES6+)
